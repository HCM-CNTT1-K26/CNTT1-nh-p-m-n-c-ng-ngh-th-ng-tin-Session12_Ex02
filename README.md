### PHẦN 2. TRIỂN KHAI FILE

* **Word:** Áp dụng chuẩn Heading 1, 2. Bấm chuột phải vào mục lục chọn *Update Field -> Update entire table* rồi mới lưu.
* **Excel:**
* Đảm bảo bảng dữ liệu sạch (1 dòng tiêu đề, không để dòng tổng kết ngang giữa bảng).
* Bấm `Ctrl + Shift + L` mở bộ lọc: Cột Khoa chọn **CNTT**, cột Chuyên cần lọc điều kiện **Nhỏ hơn 7**.


* **PowerPoint:** Dùng Dark Theme (nền Navy tối, chữ trắng, điểm nhấn cam) để đạt độ tương phản cao, trình bày luồng học tập theo 3 vùng rõ ràng.

### PHẦN 3. XỬ LỖI TÌM KIẾM KHÔNG RA KẾT QUẢ (DÙ THẤY TÊN)

* **Nguyên nhân:** Dữ liệu dính khoảng trắng ẩn (ví dụ: `"Nguyễn Văn A "`).
* **Cách sửa bằng TRIM:** Tạo cột phụ, dùng hàm `=TRIM(Ô_bị_lỗi)` để lọc sạch khoảng thừa, sau đó *Paste Values* đè lại cột cũ rồi chạy lại bộ lọc.
